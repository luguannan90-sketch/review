# 论文段落组织与来源核验

## 根据材料决定交付形态

已有段落：保守润色。已有结果和图表：可起草相应段落。只有想法/计划：写研究设想或明确带缺口的框架，不用过去时制造完成状态。没有附件或数据时不能声称看过它们。

缺信息只标具体缺项，例如 `【待补：测试集划分及独立构型数】`。不能塞看似合理的数值后让用户自行核对。最终可投稿稿件不能留隐藏占位符；缺项没有解决时说明仍是草稿。

## 各部分的写作重点

| 部分 | 用什么组织 | 避免什么 |
| --- | --- | --- |
| 标题 | 材料/对象、实际方法或发现，按用户要求长度 | 没核实的首次、颠覆性和广泛外推 |
| 摘要 | 具体问题、实际方法、关键结果、受证据约束的结论 | 没结果编结果；背景占据全文；未定义缩写堆叠 |
| 引言 | 已核实的背景与进展、具体未解问题、本工作的实际切入点 | “研究很少”当事实；用年代流水账代替问题；自动宣称首创 |
| 计算/实验方法 | 真实设置、标签、划分、评价口径和复现所需条件 | 用软件默认值补缺项；把计划写成执行过 |
| 结果与讨论 | 图表实际观察→比较→有限度解释→适用范围，按需要组合 | 逐句念图；相关当因果；用有限测试支撑全体系泛化 |
| 结论 | 回答研究问题、最重要且已有的结果、必要限制 | 引入新数据；与摘要同义复读；宏大前景代替结论 |
| 图表标题/图注 | 图中对象、面板、符号/颜色、条件、单位与误差含义 | 猜曲线来源；发明误差条定义或重复次数 |
| 审稿回复 | 实际意见→回应及证据→实际修改位置；不同意时给理由 | 虚构新增实验、计算、页码、行号；承诺已完成尚未开展的工作 |

不要把上表当固定句序或每段必须出现的四句话。正文以连贯段落为主；有比较、参数或并列项目时再用表格或列表。已有期刊结构、LaTeX 标签和引用格式保持一致。

## 引文与证据的操作边界

1. 语言润色通常不需额外搜文献。保留原引文，未访问原文时不要声明“引文已核实”。新增科学主张须有用户材料或实际核实来源；否则留待补提示，不虚构引文。
2. 用户要求补文献、写综述或核验主张时，先用可用检索工具找出版社/原论文等可靠来源。核对作者、题名、年份、来源、卷期、页码/文章号和 DOI；无 DOI 则给稳定链接，缺失或冲突写“待核实”。
3. 建立内部对应：稿件主张、引用编号/键、原文页码/章节/图表、实际阅读范围。PDF 页码和印刷页码不同应说明；网页用章节名，不伪造页码。
4. 只读摘要时明确“仅摘要”，不得靠摘要补正文的方法参数、图号或机理细节。预印本、正式出版版、修订版不混用；综述转述不冒充读过被引原文。
5. 相近对象的结果不自动支持本材料、温压、缺陷、电场或尺寸条件。强调创新前核对最相关基线；没充分检索就不写“首次/填补空白”。
6. 用户要求正式参考文献表时用指定学校/期刊格式；未指定且影响交付时询问。可先交付不依赖格式的正文和核实记录，不擅自声称符合某个标准。
7. 纯润色保留引用键及编号。确需增删或重排时检查全文对应关系；只有局部文本时不能保证全文编号一致，须说明核验范围。

## 交付前的语义对照

检查输入和成稿是否对应同一对象、数据、归因、条件和结论强度。重点看：only/within/under、may/suggest、未/尚/计划、per atom/per cell、电子/离子、实验/计算、相关/因果，以及模型使用/微调/开发的差别。发现错误时说明依据和建议，不把“原文如此”当作继续强化错误的理由。

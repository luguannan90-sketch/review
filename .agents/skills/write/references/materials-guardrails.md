# 计算材料写作的证据边界

按当前段落选择相关检查，不能把这份清单变成要求每篇论文完成所有实验的统一标准。缺少报告写“未报告/待核实”，不能直接写成“作者未做”。以下是主张审查规则，不是用户已经完成的工作。

## DFT、VASP 与数值结果

- 分开理论/近似/软件/数值求解：DFT 不等于某个泛函，PBE 不等于 VASP，SCF 收敛不等于目标性质已经收敛。
- 写方法时仅采用实际提供的材料结构、晶相、超胞、缺陷及电荷态、泛函、PAW/势文件标识、截断能、k 点、收敛条件，以及相关的自旋、SOC、U、色散等。按问题选择；不拿“常用设置”填充缺失记录，不上传势文件。
- 区分每晶胞/每原子能量、能量差与参考态、力和应力；比较须说明同一口径和条件。没有换算依据不变更单位和符号。
- 结构优化、声子、有限时长 MD 和自由能证据回答不同问题。不能把“优化完成”写成动力学稳定，把“这段 MD 没崩溃”写成所有温度下热力学稳定。小虚频也不能脱离收敛、声学支及目标相直接下结论。
- 计算与实测不一致时，先检查物理模型、数值误差及条件差异；不凭一个吻合点写“实验验证了全部模型”。

## 机器学习原子间势与物性预测

- 说明输入、标签来源、学习目标、实际输出和用途。分别记录能量、力、应力/维里、偶极/极化等标签；不能因为用了 MACE、NEP 或 NequIP 就默认支持任何电学性质。
- 普通能量/力 checkpoint 不应被直接描述为能输出介电响应或电场响应；若通过显式场依赖模型、额外性质模型、响应公式或其他流程得到，必须写明实际依据和验证。对特殊模型只按其已核实接口与输出陈述。
- 区分模型架构、预训练 checkpoint、微调和自行开发。注明当前使用的版本/模型与覆盖元素、训练条件；不在 skill 中固定“最新版/最佳模型”。MACE 官方模型表显示不同 checkpoint 的标签、理论层级和适用系统不同，不能互换。
- 数据帧数不等于独立样本数。同一轨迹邻近帧的随机划分不能自动支持跨温度、跨相、跨组分或缺陷的外推主张。只有实际可用划分证据时才评价是否泄漏。
- 报告 MAE/RMSE、能量是否按原子归一、力是分量还是模长、应力还是维里及相应单位；比较前核对定义。不能把训练误差当测试误差，也不能把测试误差下降自动写成物性和长时 MD 都准确。
- 对照使用了哪些数据、参考标签和计算成本必须有来源。超越某一势模型不等于超越 DFT 的真实精度；拟合 DFT 标签的误差与相对实验的误差分开。
- 有主动学习或不确定性模型时，只有报告了对应结果才能说“不确定性已校准/外推可靠”。

## 铁电、压电、介电与电场响应

- 非零极化、极性结构或压电响应不单独证明可切换的铁电性。文字应对应实际提供的极化、路径、翻转或其他证据，不凭材料名称替作者确认铁电性。
- 介电张量区分固定离子（电子）响应、离子弛豫贡献及所用条件下的总响应；静态、光学/频率相关、有限温度和非线性响应不能混称。`LEPSILON` 的固定离子结果不能直接叫作已经包含离子贡献的总静态介电常数。
- `LCALCPOL` 用于 Berry 相电子极化计算；写极化差、自发极化时检查离子贡献、参考结构、绝缘路径和分支处理。单次输出不能直接代替无歧义的自发极化与翻转结论。
- 保留方向、坐标系、张量分量及机械边界。压电 e 与 d 不是同一个系数，不能把 C/m² 与 pC/N 的数值互换；需要转换时核对定义、弹性关系和约定，另行计算并说明。
- 二维/薄膜含真空超胞的体积归一化响应须说明约定；不要把不同真空层或有效厚度下的表观常数直接比作材料性能差异。
- 理想晶体的计算响应不能直接推出实际薄膜的击穿场强、疲劳、储能或器件性能。厚度、缺陷、电极、频率、温度、退极化场和边界条件按论点选择；缺少证据时只提出待验证关联。
- 声子软化与介电增强同时出现只支持相应关联；若要写机制已证实，应有与所提机制匹配的模式分解、响应分析、对照或其他证据，不能凭相关性补写。

## 核实入口与阅读范围

这些链接是本 skill 编写时实际查阅的官方网页，不是用户论文的自动参考文献。使用时针对具体版本和主张重新核查；不要把网页提到的论文当作已经读过的全文。

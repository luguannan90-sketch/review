# meeting：科研会议助手

覆盖会前预习与汇报准备、分段材料接收、会后纪要、通俗理解、个人复盘和按日期导出。适合科研初学者参加计算材料、机器学习势、铁电及计算力学会议，也可处理其他科研主题。

## 使用示例

- `$meeting 我马上听这个报告，根据通知给我做十分钟预习。`
- `$meeting 我会分段发录音转写，等我说发完了再整理报告和问答。`
- `$meeting 这是会议逐字稿，生成TXT纪要，放入我指定的会议文件夹。`
- `$meeting 我没听懂今天会议，先用基本原理讲清楚。`
- `$meeting 帮我写一段发给老师的学习收获，只起草。`
- `$meeting 把这些会议按日期整理，标出哪些只是预习。`

纯同传继续使用仓库已有的 `translate`；`meeting` 不替代录音或转写引擎。只要求预习时不会自动生成会后纪要，也不要求连接Notion。

## 目录

`SKILL.md` 是入口，`references/` 按当前阶段读取。`SOURCE.md` 记录开源来源、适配取舍、许可证和固定版本；`evaluations/scenarios.md` 提供维护时的场景检查。

## 安装

将本目录完整复制到所用工具支持的个人技能目录，保留 `SKILL.md`、`references/`、元数据和许可文件。Codex常用位置包括 `~/.agents/skills/meeting` 或 `~/.codex/skills/meeting`；根据本机已有配置选择一个，避免重复安装。新会话中的技能列表是否发现 `meeting`，需以实际环境为准。

# 物理学科研同声传译员：安装与使用

显示名称：物理学科研同声传译员。技能标识：`translate`。

## Codex 本地安装

1. 解压 `translate.zip`，得到同名文件夹。
2. 将整个文件夹放入个人技能目录 `~/.agents/skills/`，最终文件路径应为 `~/.agents/skills/translate/SKILL.md`。保留 `agents/openai.yaml`，它提供中文显示名称。
3. 在技能选择器中检查是否出现该技能；未出现时重新启动 Codex。
4. 在 Codex CLI 或 IDE 扩展中输入下面的触发语，或通过 `/skills` 选择该技能：

```text
$translate 进入科研英译中模式，只翻译，不解释、不回答。
```

官方当前文档列出的个人目录是 `~/.agents/skills/`。如果某个旧环境只识别 `~/.codex/skills/`，以该环境实际技能列表为准；同一环境不要重复安装两份。

本次交付提供文件和安装说明，未修改你的个人技能目录；另按你的要求上传至 GitHub 仓库。

## ChatGPT 使用

- 桌面端若已能在技能列表中发现此技能，输入 `@`，选择“物理学科研同声传译员”，再提供英语内容。
- 如果没有技能入口或技能未被发现，打开 `CHATGPT-PROMPT.txt`，将完整内容粘贴到一个专用聊天中，再开启该聊天支持的语音模式或提供可读取的音频/英文文本。这是提示词复用，不等同于安装技能；单纯上传 ZIP 也不代表完成安装。

## 声音输入与控制

只有通过语音模式实际传入声音，或提供当前环境能够读取的音频，模型才能处理声音；英文字幕和转写稿也可直接翻译。开启语音会话及麦克风权限的步骤，以当前客户端界面为准。

本技能不会持续监听电脑音频。电脑里播放的讲座不会仅因启用技能就自动传入；也不保证零延迟、连续全双工同传。首次使用可用一段短音频核对专业术语和数字。

讲者的英语问题仍只翻译、不回答。听不清的局部标为“[听不清]”。可对译员说或输入“暂停翻译”“继续翻译”“退出翻译模式”；为避免与讲座原话混淆，优先用文字控制。

# 物理学科研同声传译员：同传与会议纪要

技能标识：`translate`。支持同传、纪要及两者结合。

## 使用

默认调用：

```text
$translate 开始同传并整理会议纪要。
```

讲座进行时只输出中文译文，不解释、不回答。你说“结束会议”或“结束讲座”后，生成中文纪要；会中说“生成纪要”可先整理当前内容，然后继续。

其他用法：

```text
$translate 只同传。
$translate 只做纪要。请根据下面的转写稿整理。
```

纪要包括实际出现的议题、汇报结果、讨论与问答、明确决定、待办和未决问题。负责人、截止时间、验收要求未提到时写“未明确”；科研设想不写成已验证结果，没有答案的问题不自行解答。

“暂停翻译”只暂停译文输出，实际收到的内容仍可用于纪要；“暂停记录”暂停两项处理，恢复前的内容不纳入纪要。“继续翻译／继续记录”恢复对应功能。“新会议”切换记录范围；“退出翻译模式”退出技能。优先通过文字发送控制指令，避免与讲座原话混淆。

## 本地安装与更新

将 ZIP 解压所得的 `translate` 文件夹放入 `~/.agents/skills/`，使 `~/.agents/skills/translate/SKILL.md` 存在。保留 `agents/openai.yaml`，它提供中文显示名称。更新前检查是否有自己的修改；确认后用新版文件替换原技能目录中的对应文件。若技能列表没有刷新，重启 Codex。

在 Codex CLI 或 IDE 扩展中用 `$translate` 或 `/skills` 选择；桌面端若技能已出现在选择器中，可用界面中的技能入口选择。在 ChatGPT 的技能选择器中可输入 `@` 选择。

没有技能入口时，将 `CHATGPT-PROMPT.txt` 全文粘贴到专用 ChatGPT 聊天中复用；上传 ZIP 本身不等同于完成安装。

## 输入与准确性

须通过语音模式实际传入声音，或提供当前环境可读取的音频、字幕、转写稿。技能不会持续监听电脑音频，也不会自动录音或永久保存会议原文；不保证零延迟同传。纪要仅依据生成时仍可访问的内容，收到部分材料时明确标注覆盖范围。长讲座建议保留完整转写稿以便核对和补全。

已检查技能文件结构及压缩包内容；未进行真实语音会话或音频翻译测试。

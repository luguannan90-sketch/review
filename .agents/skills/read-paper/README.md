# read paper

面向计算材料、DFT、机器学习力场、铁电/压电/介电研究的中文论文精读 skill。按以下固定结构输出，并保留全部子栏目：

- 📜 研究核心：⚙️ 内容、💡 创新点、🧩 不足
- 🔁 研究内容：💧 数据、👩🏻💻 方法、🔬 实验、📜 结论
- 🤔 个人总结：🙋♀️ 重点记录、📌 待解决、💭 思考启发

## 使用

在 Codex 中附上论文 PDF、DOI 或链接，然后输入：

```text
$read-paper 帮我精读这篇论文，按照我的框架输出；先解释研究对象与问题，标明原文位置、阅读范围和待核实内容。
```

仅有摘要时只做摘要范围内的初读；未读到的内容明确标记。没有用户个人想法时，个人总结是供用户判断的建议。skill 不能保证消除模型误读，也不替代对关键图表、计算和实验的独立核查。

## 安装到其他设备

把整个 `read-paper` 文件夹放入该设备的 Codex 用户技能目录 `~/.codex/skills/`，或项目内的 `.agents/skills/`。不要只复制 SKILL.md；模板和参考文件需要一并保留。下次对话使用 `$read-paper`；若列表尚未刷新，重新打开对话或应用。

技能使用宿主现有的文件/PDF读取和检索能力，本包不安装额外 Python 库、不需要单独 API key。保存或上传每次笔记仍需对应用户指令，不自动把论文原文上传到 GitHub。

# 可追溯的证据评价

改编自 K-Dense 的 scientific-critical-thinking。来源、版本与 MIT 许可见 [SOURCE.md](../SOURCE.md) 和 [LICENSE.txt](../LICENSE.txt)。以下是评价方法，不是对任何具体论文的实证结论。

1. **先固定要评价的结论。** 明确对象、对照、结果量、条件和独立采样单位；区分描述性、预测性与机制/因果性主张。
2. **先提取，再判断。** 找到原始结果、数量、误差/不确定性、方法和补充材料的位置；把缺少报告与已证明没有做分开。
3. **检查研究设计。** 方法能否回答问题？对照是否可比？样本间是否依赖？是否存在选择、测量、混杂、多重比较或模型假设问题？拟合良好、优化收敛不能证明参数唯一或因果成立。
4. **选择适合领域的评价方式。** 报告完整性、偏差风险和整体证据强度不同，不能用一个勾选总分代替科学判断。不要把临床试验的 GRADE/Cochrane 体系机械套到 DFT 或机器学习势论文上。
5. **保持结论的范围。** 检查独立重复、数据重叠、未覆盖条件和适用范围；论文证据支持到哪里，笔记就写到哪里。
6. **给出具体、适度的批评。** 每项担忧包括原文位置、观察、对主张的影响、不确定性与可行补救。说明优点，不为了展示批判性堆砌无关问题。

始终分清：观察与解释、相关与因果、统计与实际意义、探索与确认、已知与未知、反对某主张的证据与未能支持该主张。

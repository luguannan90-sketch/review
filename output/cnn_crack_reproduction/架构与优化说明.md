# CNN 项目架构与模型优化

当前主文件为 `CNN混凝土裂缝识别复现.ipynb`，继续采用一个 Notebook 分块运行的方式。模型优化在新实验目录保存，原始实验结果保留。

## 整体架构

```text
实验配置（第 2 节）
  ↓
数据预处理、标签映射、固定分组（第 4–8 节）
  ↓
模型工厂：选择原 CNN 或改进 CNN（第 9 节）
  ↓
训练、统一指标、验证（第 10–14 节）
  ↓
保存配置、划分、模型与曲线（第 15–16 节）
  ↓
按模型文件自动加载网络（第 17 节）
  ↓
训练/验证诊断、误判图、最终测试、单图预测（第 18–21 节）
```

第 22 节是可选小样本诊断，不属于常规训练路线。最终测试默认关闭。

## 模型如何优化

原模型保留为 `ConcreteCrackCNN`，仍能加载之前的 `model_best.pt`。原模型共有 12,850,530 个参数，主要集中在 `100352 → 128` 的全连接层。

新模型为 `ImprovedCrackCNN`：

```text
RGB 224×224
→ Conv 3→16 + BatchNorm + ReLU + MaxPool
→ Conv 16→32 + BatchNorm + ReLU + MaxPool
→ Conv 32→64 + BatchNorm + ReLU + MaxPool
→ AdaptiveAvgPool 4×4
→ Flatten 1024
→ Linear 1024→64 + ReLU + Dropout(0.3)
→ Linear 64→2
```

新模型有 89,426 个参数，比原模型减少约 99.30%。较小的分类层减少参数和模型文件体积；BatchNorm 调整中间特征的尺度，Dropout 在训练时随机屏蔽部分特征。验证和预测时调用 `eval()`，使用 BatchNorm 保存的统计量并关闭 Dropout。

这些修改构成一个组合方案。参数更少不保证识别率更高，应在相同分组验证集上比较 Precision、Recall、F1 和 Balanced Accuracy。

## 哪些设置集中管理

在第 2 节修改：

- `MODEL_NAME`：`ConcreteCrackCNN` 或 `ImprovedCrackCNN`。
- `SPLIT_SEED`：只控制照片分组划分，实验对照时固定为 42。
- `SEED`：控制模型初始化、训练顺序和增强的随机性。
- `USE_FLIPS`：是否使用水平和垂直翻转。
- `LEARNING_RATE`、`BATCH_SIZE`、`EPOCHS`、`PATIENCE`：训练参数。
- `EXPERIMENT_NAME`：新实验名称；已有模型的目录不能直接覆盖。
- `CHECKPOINT_OVERRIDE`：只预测时指定已有模型的路径。

这次新架构对照保持学习率 0.0001、批大小 32、轮数上限 30、早停等待 5 轮，以及原来的类别权重和分组。未额外加入学习率调度、预训练下载或新的采样方法。

## 保存和加载

模型文件记录架构名称、模型构造参数、类别顺序、输入尺寸和归一化设置。第 17 节根据这些信息自动创建正确的网络，并严格加载参数。

预测现有图片时，只运行第 1、2、3、9、17、21 节。在第 21 节修改 `sample_path`。如果使用其他实验的模型，在第 2 节设置：

```python
CHECKPOINT_OVERRIDE = PROJECT_ROOT / 'artifacts' / 'group_validation_flip' / 'model_best.pt'
```

重做训练请先更改 `EXPERIMENT_NAME` 并重新运行准备单元。检查点用于加载推理；当前不提供完整优化器及随机状态的断点续训。

## 实验记录

每个正式实验目录保存：

- `config.json`：架构、参数、软件版本、随机种子与增强设置。
- `split.json`：分组、索引、相对图片路径和各类别数量。
- `history.json`：逐轮损失及验证指标，每轮更新。
- `model_best.pt`：验证 F1 最高的模型。
- `model_last.pt`：最后一轮模型。
- `metrics.json`：最佳验证结果汇总。
- `learning_curves.png`：训练与验证损失曲线。
- `diagnostics.json`：训练/验证指标及概率分布。
- `validation_misclassified.png`：部分误报和漏检图片。

测试数据未参与本轮方案选择。单次实验的提升仍需多个训练种子复核；固定分组验证集上的成绩不能直接代表其他拍摄条件或路面测试集的成绩。

## 本次运行结果

改进模型在第 24 轮触发早停，最佳模型为第 19 轮，训练耗时约 652 秒。以下比较来自已保存的两个实验记录，使用同一组 2,772 张验证图片；这是单次历史对照，不是多随机种子统计结论。

| 指标 | 原 CNN 加翻转 | 改进 CNN 加翻转 |
|---|---:|---:|
| 参数量 | 12,850,530 | 89,426 |
| Precision | 0.4908 | 0.5465 |
| Recall | 0.5597 | 0.5504 |
| F1 | 0.5230 | 0.5484 |
| Balanced Accuracy | 0.7270 | 0.7336 |
| 误报 FP | 248 | 195 |
| 漏检 FN | 188 | 192 |

这次改进主要表现为参数减少、误报减少，F1 和 BA 略有提高；裂缝召回率略降，仍漏检 192 张验证图片，不能理解为全面提升或达到可靠工程应用水平。
